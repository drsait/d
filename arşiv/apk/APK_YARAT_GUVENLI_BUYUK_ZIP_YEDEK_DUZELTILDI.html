📱 APK Oluşturucu · Ayrıntılı GitHub hata raporu

Önceki uygulamanın ZIP yükleme, GitHub Actions derleme, depo geri yükleme ve APK indirme akışı korunmuştur. Başarısızlıkta hata ayrıntıları, iş adımları ve erişilebilir tam günlükler gösterilir.

Yalnızca GitHub API isteğinde kullanılır; raporlara, indirmelere veya yerel depolamaya eklenmez. Klasik PAT için repo ve workflow izinleri; fine-grained PAT için Contents, Actions ve Workflows yazma/okuma izinleri gerekebilir. Bu HTML'yi yalnızca güvendiğin ortamda aç.

GitHub Actions günlüklerinin tarayıcı üzerinden indirilmesi, GitHub yönlendirme/CORS ve yetkilendirme kısıtları nedeniyle engellenebilir. Bu durumda iş/step sonuçları ve erişilebilen check-run açıklamaları kaydedilir; tam günlük için GitHub bağlantısı sunulur. Hiçbir araç tüm olası GitHub hatalarını kesin olarak tespit edemez; rapor erişilebilen kanıtlara dayanır. Başarılı derlemede APK artifact ZIP olarak alınır; erişim engellenirse GitHub'dan manuel indirilir. Bir derleme hâlâ sürüyorsa geçici dosyalar korunur. Tamamlanan derlemelerde önceki dosyalar geri yüklenir; commit ve Actions geçmişi kalır.
