📱 Tek Sayfa APK Oluşturucu

Android proje ZIP dosyasını seç. GitHub'a yükleme, derleme, takip ve APK indirme işlemleri bu sayfadan yürütülür.

Token alanına dokunarak telefonunun kayıtlı şifrelerinden seçim yapabilirsin (tarayıcı destekliyorsa). Bu sayfa token saklamaz; şifre yöneticin ayrı olarak saklayabilir. Klasik PAT için repo + workflow izinleri gerekir.
Hazır.
APK paketini indir

APK, GitHub Actions üzerinde derlenir. İndirme paketi ZIP biçimindedir ve içinden .apk çıkar. GitHub'ın artifact indirme yönlendirmesi tarayıcı güvenlik kısıtına takılırsa doğrudan indirme yerine bilgilendirici hata gösterilir. Sayfayı güvenilir bir HTTPS adresinden aç.
