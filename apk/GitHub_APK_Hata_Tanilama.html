Anahtar yalnızca GitHub API isteklerinde kullanılır; tarayıcıda saklanmaz. Klasik PAT için repo + workflow izinleri gerekir.

APK paketini indir

APK, GitHub Actions üzerinde derlenir. İndirme paketi ZIP biçimindedir ve içinden .apk çıkar. GitHub'ın artifact indirme yönlendirmesi tarayıcı güvenlik kısıtına takılırsa doğrudan indirme yerine bilgilendirici hata gösterilir. Sayfayı güvenilir bir HTTPS adresinden aç.
