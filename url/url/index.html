Kurulum bilgileri

GitHub'da herkese açık bir depo açıp bu dosyaları yükleyin. Settings → Pages → Deploy from a branch → main / root seçin. Bu kurulumda adres https://drsait.github.io/d/url/kod şeklindedir.

GitHub'da fine-grained token oluşturun; yalnızca bu depoya Contents: Read and write izni verin. Tokenı bu sayfaya girin.
