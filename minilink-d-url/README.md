# MiniLink - drsait/d/url

1. ZIP içindeki **404.html** ve **.nojekyll** dosyalarını `drsait/d` deposunun **köküne** yükleyin.
2. **url** klasörünü içindeki `index.html` ve `links.json` ile aynı depoya yükleyin.
3. GitHub deposunda Settings > Pages > Deploy from a branch > main / (root) > Save.
4. https://drsait.github.io/d/url/ adresini açın.
5. GitHub fine-grained personal access token oluşturun. Repository access: yalnızca `drsait/d`; Contents: Read and write. Anahtarı sayfada girin.
6. Uzun URL ve isterseniz özel kod yazıp oluşturun. Kısa URL: https://drsait.github.io/d/url/KOD

**Önemli:** GitHub Pages özel 404 sayfasını depo kökünden okur. Bu nedenle kökteki 404.html zorunludur. Mevcut bir kök 404.html dosyanız varsa üzerine yazmadan önce birleştirin. Token'ı kimseyle paylaşmayın. Yeni linkler GitHub Pages yeniden yayınlandıktan sonra çalışır. Tıklama istatistiği yoktur.
